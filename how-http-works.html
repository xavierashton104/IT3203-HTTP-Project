How HTTP Works

HTTP lets a browser request information from a web server.

The Basic Process

  1. The browser sends a request for a resource.
  2. The server receives and processes the request.
  3. The server sends back a response.
  4. The browser uses the response to display the content.

One Page, Multiple Request

When you open my homepage, the browser request index.html from Github. The HTML then tells the browser where to find style.css and http-diagram.png. If the browser doesn't already have copies of those files, then it'll send a separate request for them. That's why opening one page can involve more than one HTTP request.

Key HTTP Concepts

These seven terms help explain how HTTP works.

Client
Software that sends requests, such as a web browser.
Server
Software that receives requests and sends responses.
Request
A message asking a server to perform an action on a resource.
Response
The message a server sends back after receiving a request.
Method
The requested action. For example, GET requests a representation of a resource.
Status Code
A three-digit number describing the result, such as 200 for success.
Header
A field containing extra information about a request or response.
